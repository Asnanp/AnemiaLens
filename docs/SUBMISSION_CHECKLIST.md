# Submission Checklist

Use this file to prepare the final hackathon submission.

## Required deliverables

- Live deployed URL
- Public GitHub repository
- 3 to 5 minute video
- Impact narrative
- AI stack explanation

## Repo package

- [ ] README is accurate and matches the real stack
- [ ] `docs/IMPACT_NARRATIVE.md` is ready to reuse in the submission form
- [ ] `docs/AI_STACK.md` is ready to reuse in the submission form
- [ ] `docs/VIDEO_SCRIPT.md` is ready for recording
- [ ] `docs/JUDGE_GUIDE.md` matches the live demo order

## Product checks

- [ ] Frontend builds successfully
- [ ] Backend tests pass
- [ ] Quality gate blocks weak images
- [ ] Valid image produces risk, confidence, and next steps
- [ ] Guidance stays non-diagnostic
- [ ] Handoff summary can be copied or downloaded

## Story checks

- [ ] Problem statement is clear in one sentence
- [ ] Social-good impact is obvious
- [ ] GenAI role is essential, not cosmetic
- [ ] Safety posture is clearly explained
- [ ] Limitations are stated honestly

## Video checks

- [ ] Show the bad-image retake block
- [ ] Show one successful analysis
- [ ] Show grounded GenAI guidance
- [ ] Show clinician handoff output
- [ ] Close with impact plus safety disclaimer
